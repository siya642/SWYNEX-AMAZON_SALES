# 🛒 Amazon Sales Data Analysis using SQL

## 📌 Project Overview

This project focuses on analyzing Amazon sales data using **SQL and MySQL Workbench** to extract meaningful business insights.

## 🎯 Objectives

- Analyze total orders and revenue.
- Find average, minimum, and maximum product prices.
- Analyze product sales and quantities.
- Identify top-performing brands.
- Explore monthly and yearly revenue.
- Analyze popular payment methods.
- Find top revenue-generating countries.

## 🛠️ Tools Used

- MySQL Workbench
- SQL

## 📊 SQL Concepts Used

- SELECT
- COUNT(), SUM(), AVG(), MIN(), MAX()
- GROUP BY
- ORDER BY
- LIMIT
- Date Functions
- Aggregate Functions

## 📁 Project Files

- `Amazon_Sales_Analysis.sql` – SQL queries used for data analysis.
